# Atajos de teclado

## Herramientas (sin modificadores)

| Tecla | Herramienta | Tecla | Herramienta |
|---|---|---|---|
| Q | Selección libre | R | Rectángulo |
| S | Selección | U | Rectángulo redondeado |
| P | Lápiz | O | Elipse |
| B | Pincel | G | Polígono |
| A | Aerógrafo | W | Flecha |
| E | Borrador | H | Resaltador |
| F | Relleno | K | Ocultar |
| I | Cuentagotas | N | Marcador numerado |
| T | Texto | Z | Lupa |
| L | Línea | X | Intercambiar colores |
| C | Curva | D | Nube de revisión |

## Al dibujar

| Tecla | Efecto |
|---|---|
| ⇧ | Línea y flecha a 0°/45°/90°; formas con proporción 1:1; selección estirada en proporción |
| ⌥ | Duplicar la selección al arrastrar; con la lupa, alejar |
| Flechas | Mover la selección 1 px (⇧: 10 px) |
| Intro | Confirmar forma, polígono, nube o selección |
| Escape | Descartar lo que esté a medias; con selección, confirmarla; con un polígono de 3 vértices, cerrarlo; con una nube de 3 vértices, cerrarla (sigue editable) |
| ⌫ / Supr | Borrar la selección |

## Archivo y edición

| Atajo | Acción |
|---|---|
| ⌘N | Nuevo |
| ⇧⌘N | Nuevo desde el portapapeles |
| ⌥⌘5 | Nueva captura de pantalla |
| ⌘O / ⌘S | Abrir / Guardar |
| ⌘P | Imprimir |
| ⌘Z / ⇧⌘Z | Deshacer / Rehacer |
| ⌘X / ⌘C / ⌘V | Cortar / Copiar / Pegar |
| ⇧⌘C | Copiar toda la imagen |
| ⇧⌘V | Pegar como documento nuevo |
| ⌘A | Seleccionar todo |

## Imagen

| Atajo | Acción |
|---|---|
| ⌘R | Cambiar tamaño e inclinar |
| ⌘E | Tamaño del lienzo |
| ⌘K | Recortar a la selección |
| ⌘I | Invertir colores |
| ⌥⌘R / ⌥⌘L | Girar 90° a la derecha / izquierda |
| ⇧⌘⌫ | Borrar imagen |

## Visualización

| Atajo | Acción |
|---|---|
| ⌘+ / ⌘− | Acercar / Alejar |
| ⌘0 | Tamaño real |
| ⌘9 | Ajustar a la ventana |
| ⌘G | Mostrar u ocultar la cuadrícula |
| ⌥⌘E | Mostrar u ocultar los puntos de control del lienzo |
