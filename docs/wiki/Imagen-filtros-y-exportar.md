# Imagen, filtros y exportar

## Menú Imagen

Si hay una selección, las transformaciones se aplican solo a ella.

| Acción | Atajo |
|---|---|
| Voltear horizontal / verticalmente | — |
| Girar 90° a la derecha | ⌥⌘R |
| Girar 90° a la izquierda | ⌥⌘L |
| Girar 180° | — |
| Cambiar tamaño e inclinar… (porcentaje o píxeles, proporción, suave o vecino más cercano) | ⌘R |
| Tamaño del lienzo… (sin escalar, con anclaje) | ⌘E |
| Recortar a la selección | ⌘K |
| Invertir colores | ⌘I |
| Borrar imagen (o la selección) | ⇧⌘⌫ |

## Filtros

Menú **Filtros**, con vista previa en vivo. Se aplican a la imagen o a la selección y se pueden deshacer:

- Escala de grises, sepia e invertir.
- Brillo, contraste y saturación.
- Desenfoque y enfocar.
- Pixelar y posterizar.
- Umbral (blanco y negro).

## Pixel art

- **Archivo › Nuevo pixel art:** lienzos transparentes de 16 × 16, 32 × 32 o 64 × 64.
- **Modo pixel** (Visualización): quita el suavizado de texto, flechas, resaltador y marcadores.
- **Simetría** horizontal y vertical (Visualización › Simetría) para lápiz, pincel, borrador y aerógrafo.
- Paletas limitadas como Retro 8 bits o Verde 4 tonos (ver [Colores y paletas](Colores-y-paletas)).

## Documentos nuevos

| Acción | Atajo |
|---|---|
| Nuevo | ⌘N |
| Nuevo desde el portapapeles | ⇧⌘N |
| Nueva captura de pantalla… (ventana o pantalla; necesita el permiso de Grabación de pantalla) | ⌥⌘5 |

También puedes soltar imágenes sobre la ventana o el icono del Dock para abrirlas.

## Guardar y exportar

- Formatos: **PNG, JPEG, BMP, GIF, TIFF y HEIC**. JPEG y BMP no tienen transparencia (se aplanan sobre blanco).
- El formato por defecto y la calidad JPEG/HEIC se eligen en [Ajustes](Ajustes).
- **Archivo › Exportar a escala:** PNG ×2, ×4 u ×8 con vecino más cercano (ideal para pixel art).
- **Compartir** (barra superior) e **Imprimir** (⌘P).
- Autoguardado y versiones de macOS (Archivo › Volver a).
